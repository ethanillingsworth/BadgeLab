# BadgeLab

A collection of API endpoints to simplify GitHub README badges. With predefined badges for standard technologies and platforms, along with custom badges you can make yourself.


## Predefined Badges

Badges are defined within each section below and can be accessed with the [badge route](https://badgelab.dev/#/Badges/badge_api_badge__id__get)

You can find an entire table full of every badge in every style with the [badgeTable route](https://badgelab.dev/api/badgeTable)
